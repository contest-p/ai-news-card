# 개인화 뉴스 브리핑

## 작업 폴더

| 폴더 | 담당 | 작업 범위 |
|---|---|---|
| `engine/` | 박경연 | 뉴스 수집·선별·RAG·AI 카드 생성·이미지 변환·메일 발송 |
| `backend/` | 고승희 | FastAPI·사용자·구독·피드백·권한·DB 변경 관리 |
| `frontend/` | 김현서 | 웹 화면·로그인·API 연동·카드 템플릿 |
| `deployment-qa/` | 윤지민 | 배포·운영 안내·뉴스 소스 검증·QA 결과 |
| `docs/` | 전원, 박경연 취합 | 공통 PRD·개인 PRD·공유 문서 |

각 담당자는 작업 폴더 안의 세부 파일과 폴더를 직접 구성합니다.
카드 템플릿의 공유 위치와 연결 방식은 김현서·박경연이 합의합니다.
발송 DB 코드는 박경연이 작성하고 고승희가 리뷰하여 전체 DB 변경에 통합합니다.
도구가 요구하는 저장소 루트의 배포 설정·GitHub Actions 파일은 관련 담당자와 공유한 뒤 추가합니다.

## 시작 기준

- `docs/`의 공통 PRD v0.4와 본인의 개인 PRD v0.3(Firebase 반영판)를 함께 확인합니다.
- 공통 PRD의 연결 규격 중 합의 전 초안은 관련 담당자와 먼저 확인합니다.
- 샘플 구독·API 응답·카드 데이터·템플릿 연결 방식을 맞춘 뒤 병렬 개발합니다.
- 각자 작업 브랜치에서 커밋·푸시하고, PR 검토 후 `main`에 병합하는 방식을 제안합니다. 실제 브랜치 규칙은 팀이 합의합니다.
- API 키·비밀번호·실제 사용자 개인정보는 저장소에 올리지 않습니다.

빈 작업 폴더의 `.gitkeep`은 Git에 폴더를 포함하기 위한 빈 파일입니다. 실제 작업 파일이 생기면 삭제해도 됩니다.

PRD 5개는 2026-10-05 팀 결정에 따라 Firebase Authentication·Cloud Firestore 기준으로 갱신했습니다. 기존 파일명은 링크 유지를 위해 보존합니다. 개인 PRD는 GitHub에서 읽기 편하도록 확장자만 `.md`로 정리했습니다.
공통 PRD가 참조하는 시나리오·마일스톤 문서 등은 아직 이 저장소에 포함하지 않았습니다.
