# 샘플 데이터

이 폴더는 가상 입력 데이터입니다. 실제 수집 결과나 생성된 카드 이미지 보관함이 아닙니다.

| 파일 | 내용 | 사용처 |
|---|---|---|
| selection.json | 가상 구독·기사·발송 이력 | 기사 선별·수집 테스트, 여러 데모 |
| rag.json | 현재·과거 가상 기사 | RAG·카드·생성 데모 |
| cards.json | 가상 AI 응답과 출처명 | 카드·생성 데모 |
| mail.json | 가상 발신/수신 주소·웹 주소·토큰·구독 기간 | 3종 메일 미리보기 데모 |
| collection/sources.json | 로컬 RSS·HTML 연결 목록 | 수집 코드·테스트·데모 |
| collection/economy.xml | 가상 RSS | 수집 코드·테스트·데모 |
| collection/economy.html, rate.html | 가상 기사 본문 | 수집 코드·테스트·데모 |

## 삭제 기준

자동 테스트가 이 데이터를 읽으므로 프로젝트 완성 후에도 폴더 전체를 삭제하지 않습니다. 수동 확인에만 쓰는 새 샘플을 추가한다면 자동 테스트용 데이터와 별도 하위 폴더로 구분하고 사용처를 기록하세요.

코드 안에서 만드는 가상 데이터도 `tests/`, `tools/render_layout_check.py` 등에 있습니다. 현재 코드 수정 없이 유지했습니다.

생성된 PNG·HTML·메일 미리보기는 `.engine-local/`에 저장하도록 되어 있습니다. 해당 위치에는 호출·전송 상태도 있으므로 전체 삭제 대신 미리보기 결과만 구별해 정리합니다. 자세한 기준은 [구조 안내](../docs/STRUCTURE.md)를 참고하세요.

새 `mail_types_demo` 결과는 `engine/.engine-local/previews/mail-types/`로 분리했습니다. 이 하위 폴더에는 가상 미리보기만 있으므로 검수 후 삭제해도 호출·발송 상태 기록에 영향을 주지 않습니다.
