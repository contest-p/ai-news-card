# 기사 DB 변경 기록 — 2026-10-05 KST

## 확정된 사용자 결정

DB 담당자가 Supabase 오류로 Firebase로 변경했다는 사용자의 최신 지시를 반영합니다. 공통 PRD v0.3의 PostgreSQL·pgvector 부분과 차이가 있으므로 변경 이력을 별도로 기록합니다. 기존 PRD의 정책·원문은 수정하지 않습니다.

사용자가 **Cloud Firestore**임을 추가 확인했습니다. 사용자·로그인·구독·피드백 구현은 기존 담당자 소유이며 엔진이 대신 구현하지 않습니다.

## 현재 독립적으로 확인할 수 있는 것

`python -m engine.store_demo`는 외부 DB 없이 기사 수집·샘플 저장·재저장·수정 버전·선별을 확인합니다. 같은 URL은 1건, 같은 내용은 같은 버전, 변경된 내용은 새 버전으로 기록합니다. 이전 본문은 별도 버전으로 보관합니다. 메모리 샘플은 프로그램 종료 시 사라집니다.

이번 작업에서 잠시 작성했던 PostgreSQL 어댑터와 SQL 초안은 Firebase 결정에 따라 제거했습니다. 실제 Supabase에는 실행하지 않았습니다.

## 현재 연결 상태

기사 저장 어댑터는 Cloud Firestore용으로 작성했습니다. 실제 프로젝트 접속·권한·동시 저장·보관 정책은 아직 검증하지 않았습니다. 이전 버전 보관은 무기한 보관을 뜻하지 않습니다.

RAG는 multilingual-e5-small·384차원·cosine 방식 유지입니다. pgvector SQL은 Firebase에서 직접 실행할 수 없으며 벡터 저장·검색 연결은 후속 개발 범위입니다.

## 변경하지 않은 엔진 정책

UTC 저장·KST 발송, 구독 기간, 최근 24시간 선별, 최근 7일 sent/unknown URL 반복 방지, AI·SMTP 재시도 제한은 유지합니다. 카드 설명은 챗 API, 카드 이미지는 HTML/CSS+Playwright 방식입니다.
