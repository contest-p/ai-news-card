# 영문 뉴스 카드 한국어 번역

운영 `GenerationCardBuilder`는 기존 원문 발췌·근거 검사를 통과한 카드에서 영문 중심인 제목, 문장, 용어 설명만 한국어로 번역한다. BBC에만 한정하지 않으며 영문 과거 근거 카드도 같은 방식으로 처리한다. ICE·DHS 같은 용어 이름은 유지하고 설명을 한국어로 제공한다.

번역 입력에는 검사된 표시 문구만 전달한다. 지시문으로 사실·주체·부정·불확실성·시점 보존과 새 사실 추가 금지를 요구한다. 반환 구조, 항목 수, 한국어 여부, 숫자 표기·개수, 제목 60자·카드별 본문 400자·용어 설명 100자 제한을 검사한다. 이 검사는 의미 일치 전체를 증명하지 않으므로 원문 링크와 AI 생성 안내를 계속 제공한다.

기사 URL·게시일·원문 인용·숫자 근거·출처 식별자는 번역 응답에서 받지 않고 기존 값을 보존한다. 원문 카드 생성 기록과 번역 기록은 별도로 `engine_generation_jobs`에 저장한다. 번역 키는 원문 생성 키·카드 내용·모델·API 주소·번역 버전을 포함한다. 같은 작업의 재실행은 원문과 번역 결과를 재사용한다.

한국어 카드는 추가 API 호출이 없다. 영문 카드는 통상 번역 호출 1회가 추가된다. 번역 검증 실패와 일부 일시 오류는 최초 포함 최대 2회로 제한한다. 실패 시 영어를 대신 발송하지 않고 발송 실패로 기록한다. 요청 중단·결과 불확실 상태는 자동 재호출하지 않는다.

새 Actions 실행부터 적용되며 이미 발송된 메일이나 보관 MIME은 변경하지 않는다. 로컬 추출 데모는 기존 원문 카드 검수용으로 유지한다.
