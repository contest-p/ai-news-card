# 박경연 — 리드·핵심 엔진 PRD

## 목표
사용자의 관심에 맞는 뉴스를 고르고, 정확하게 설명하는 카드와 메일을 자동으로 보내기.

## 고정 기술스택
- Python, feedparser, trafilatura: 뉴스 수집·본문 추출
- Supabase PostgreSQL·pgvector, multilingual-e5-small: 기사 저장·검색
- 코디세이 API: AI 설명 생성. 실제 사용할 모델은 제공 여부 확인 후 선택
- HTML/CSS + Playwright/Chromium: 카드 이미지 변환
- GitHub Actions: 자동 실행 / Gmail SMTP: 메일 발송

## 만들 것
1. **뉴스 수집 기능 만들기.** 검증된 RSS에서 기사와 본문을 가져와 저장하기.
2. **중복 기사 방지 기능 만들기.** 같은 기사를 중복 저장하거나 같은 사용자에게 반복해서 보내지 않기.
3. **관심 뉴스 선택 기능 만들기.** 사용자가 입력한 키워드를 우선으로 찾고, 없으면 관심 분야에서 고르기.
4. **과거 뉴스 검색 기능 만들기.** 현재 기사를 이해하는 데 도움이 되는 과거 기사를 찾아 AI에 제공하기. 이것이 RAG 기능임.
5. **AI 카드 설명 생성·검사 기능 만들기.** 기사에 근거한 핵심 설명과 배경 설명을 만들고, 수치·대상·시점·출처를 확인하기.
6. **카드 이미지 연결하기.** 김현서가 만든 템플릿에 설명을 넣어 이미지로 변환하기.
7. **메일 본문 만들기.** 카드, 선택 이유, AI 생성 표시, 출처 링크, 피드백 링크, 웹 구독 관리 링크 넣기. 이미지가 안 보여도 설명을 읽을 수 있게 하기.
8. **자동 발송 기능 만들기.** 매시간 실행해 발송 시간이 된 구독자에게 하루 한 번 보내기. 뉴스가 없을 때와 구독이 끝났을 때의 안내 메일도 만들기.
9. **중복 발송·실패 대응 기능 만들기.** 발송 기록과 작업 상태를 저장하고, 안전하게 재실행할 수 있게 하기. 발송 관련 DB 코드도 직접 작성하고 고승희에게 리뷰받기.
10. **정리·실행 기록 연결하기.** 고승희의 개인정보 정리 기능을 자동 실행에 연결하고, 성공·실패·비용을 확인할 기록 남기기.
11. **전체 연결 확인하기.** 다른 담당자의 결과물을 연결하고, 범위 조정·문서·발표 자료를 취합하기.

## 꼭 지킬 것
- 카드 1은 핵심 설명, 카드 2는 근거가 있는 배경 설명. 배경 근거가 부족하면 카드 2는 생략하기. 자동 검사와 사람의 검수 모두 필요함.
- 같은 발송 작업을 다시 실행해도 중복 발송하지 않기. 보냈는지 불확실한 메일은 자동으로 다시 보내지 않기. 발송 직전에 해제·만료·삭제 요청 여부 확인하기.
- 한국 시간 기준으로 처리하고, 뉴스는 예정 시각부터 최대 3시간 이내에만 보내기. 다음 자정이나 구독 만료가 더 빠르면 그 전에 멈추기.
- AI 호출은 같은 생성 작업에서 처음 포함 최대 2회, SMTP 발송은 명확한 일시 실패일 때만 처음 포함 최대 3회. 재실행해도 횟수를 초기화하지 않기.

## 받아서 연결할 것
- 고승희: 오늘의 구독 정보, 발송 가능 여부, 피드백 링크용 토큰, 개인정보 정리 기능, SMTP 계정 준비 결과
- 김현서: 카드 템플릿과 샘플 미리보기
- 윤지민: 검증된 뉴스 소스, 배포 환경, 실제 메일·AI 검수 결과

## 나중에 해도 되는 것
여러 사용자에게 같은 AI 결과를 재사용하는 캐싱, 비슷한 사건 자동 묶기, 여러 언론사의 보도 자동 대조. 기본 발송 기록과 근거 검사는 생략하지 않기.

## 완료 모습
테스트 구독 정보를 받아 기사 선택 → RAG → 카드 생성 → 이미지 → 메일까지 연결되고, 재실행·해제·실패 상황에서도 발송 규칙이 지켜짐.

## AI에 작업을 맡길 때
이 PRD와 공통 PRD를 함께 전달하고, 위 기능을 작은 단위로 구현해 달라고 요청하기. 구현 방식은 AI가 제안하되 고정 기술스택과 담당 경계는 유지하기. 다른 담당자와 주고받는 데이터는 샘플을 먼저 공유하기.

> 이 문서는 쉬운 작업 안내다. 상세 날짜·보안·발송 정책은 공통 PRD v0.3을 따른다. 충돌하거나 정하지 않은 부분은 임의로 바꾸지 않고 팀에 확인한다. 일정·마일스톤은 포함하지 않는다.
