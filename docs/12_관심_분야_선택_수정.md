# 구독 관심 분야 선택 수정

2026-10-08 사용자 요청에 따라 구독 화면에서 관심 분야를 선택할 수 없는 문제를 수정했다.

## 원인과 수정

백엔드 PUBLIC_CATEGORIES가 미설정 또는 빈 값이면 /catalog가 categories=[]를 반환했다. 프론트는 이 목록을 그대로 표시하므로 선택 버튼과 신청이 비활성화됐다.

미설정·빈 값·공백만 있는 값은 기본 관심 분야 6개(경제, IT/과학, 정치, 사회, 국제, 문화)를 반환하도록 수정했다. 카탈로그와 신규 구독·설정 변경 검증은 같은 함수를 사용하므로 표시만 되는 임시 대체 목록을 프론트에 넣지 않았다.

PUBLIC_CATEGORIES에 명시적인 목록이 있으면 그대로 제한한다. 쉼표 주변 공백과 중복은 정리하고 알 수 없는 코드는 공개하지 않는다. 알려지지 않은 코드만 명시하면 선택 목록이 비고 신청도 거절된다.

이번 기본값 변경은 관심 분야 선택을 사용할 수 있게 하라는 사용자 요청을 반영한 것이다. 분야 제공은 기사 소스 검증·메일 수신 QA 완료를 의미하지 않는다. 이전 문서의 빈 값이면 전체 분야 차단 정책은 이 변경으로 대체됐다.

## 검증과 배포

외부 DB·메일을 호출하지 않는 테스트에서 미설정·빈 값·공백 값의 카탈로그, 다중 분야 신청·설정 변경, 분야 제한·미지원 코드 거절을 검증했다. 프론트 테스트는 6개 선택 버튼 표시와 선택한 분야가 신청 요청에 포함되는지 확인한다.

현재 Vercel 연결은 백엔드 팀 환경변수 조회에 403 권한 오류를 반환했다. 환경변수는 직접 수정하지 않았다. 수정된 백엔드 코드가 Production에 반영되면 빈 환경변수 상태에서도 목록이 제공된다. 배포 후 /catalog와 실제 구독 화면에서 확인해야 한다.
