# 사용자 테스트 및 피드백 기록

## 1. 테스트 개요

| 항목 | 기록 |
|---|---|
| 대상 | 실제 사용자 5명. 개인정보 대신 01~05로 표기 |
| 기간 | 2026년 10월 7일 시작, 현재 계속 진행 중 |
| 확인 시점 | 진행자가 2026년 10월 11일까지 메일 수신과 서비스 이용을 확인. 간헐적으로 메일이 도착하지 않은 경우도 있어 그때마다 수정했으며, 이후 운영 상태까지 검증했다는 뜻은 아님 |
| 진행 방식 | 웹에서 로그인·구독 등 원하는 작업을 직접 해 보고, 기능을 눌러 보며 의견을 말함. 메일 수신 여부도 확인 |
| 이용 범위 | README에 기록된 공통 결과: 로그인 → 구독 신청 → 뉴스 브리핑 메일 3회 이상 수신 |

테스트는 계속 진행 중이므로 종료일을 임의로 지정하지 않았다. 개별 참여자의 정확한 실시일, 발언 시각, 메일 수신 횟수는 별도로 기록되지 않았다. 아래 답변은 참여자 의견의 요지이며 축어록이 아니다.

## 2. 진행 질문

진행자가 실제로 요청하거나 물었던 내용의 요지다.

1. “이 웹사이트에서 하고 싶은 것을 모두 해 보세요.” 기능을 직접 눌러 보고 불편한 점을 이야기해 달라고 요청했다.
2. 화면의 이미지·색상에 대한 의견과 추가했으면 하는 기능을 물었다.
3. 뉴스 브리핑 메일이 잘 받아지는지 물었다.

## 4. 메일 수신 확인과 남은 기록

진행자는 2026년 10월 11일까지 메일 수신을 확인했지만, 테스트 중 간헐적으로 메일이 도착하지 않는 경우도 있었다고 알렸다. 그런 경우마다 수정했다. 따라서 테스트 기간 전체에 수신 오류가 없었다거나 모든 메일의 도착을 보장했다고 기록하지 않는다. 개별 미수신 일자·원인·수정 내역과 사용자별 수신 횟수는 제공된 기록만으로 특정할 수 없다.

추후 개별 실시일과 개선 후 재확인 결과가 확인되면 이 문서에 사실대로 추가한다. 계정 주소와 테스트 계정 비밀번호는 이 저장소에 기록하지 않는다.
