# 사용자 테스트 및 피드백 기록

## 테스트 개요

2026년 10월 11일부터 14일까지 실제 사용자 5명이 서비스를 직접 사용했다. 로그인과 구독 신청, 뉴스 브리핑 메일 수신을 확인하고 화면과 사용 흐름에 대한 의견을 들었다. 참여자는 개인정보를 보호하기 위해 01~05로 표기했다.

## 사용자에게 물어본 내용

1. 사이트에서 원하는 기능을 직접 눌러 보고 불편한 점을 알려 달라고 했다.
2. 화면의 글자, 이미지, 색상과 추가했으면 하는 기능에 대해 물었다.
3. 뉴스 브리핑 메일이 잘 도착하는지 물었다.
