# 사용자 테스트 및 피드백 기록

## 테스트 개요

2026년 10월 11일부터 14일까지 실제 사용자 5명이 서비스를 직접 사용했다. 로그인과 구독 신청, 뉴스 브리핑 메일 수신을 확인하고 화면과 사용 흐름에 대한 의견을 들었다. 참여자는 개인정보를 보호하기 위해 01~05로 표기했다.

## 사용자에게 물어본 내용

1. 사이트에서 원하는 기능을 직접 눌러 보고 불편한 점을 알려 달라고 했다.
2. 화면의 글자, 이미지, 색상과 추가했으면 하는 기능에 대해 물었다.
3. 뉴스 브리핑 메일이 잘 도착하는지 물었다.

## 의견을 받은 방식과 대화 예시

프런트엔드 담당 김현서는 참여자 03·04를 직접 만나 웹 화면을 함께 보며 의견을 받았다. 두 건은 구두로 진행해 대화 캡처가 없다.

테스트 중 주고받은 메시지에는 다음과 같은 표현이 남아 있다.

- 샘플 카드: “샘플카드 구성 2번 여기는 오류난거임?” ([대화 화면](assets/user-feedback/sample-card-question.png))
- 글자 크기 관련 전달 메시지: “기사 속 용어 글씨 폰트를 조금만 더 크게 하는 게 좋을 거 같다는 피드백을 받았습니다!” ([발언 화면](assets/user-feedback/glossary-font-message-edited.png))
- 영문 메일: 윤지민님 지인이 테스트 메일을 받고 “BBC 뉴스라 영문이네요...!”라고 말했다. ([발언 화면](assets/user-feedback/english-news-message-edited.png))

표에 연결한 01~05 이미지는 의견을 보기 쉽게 정리한 화면이다. 위 대화 화면 중 샘플 카드 문의는 원본 캡처이고, 글자 크기와 영문 메일 관련 화면은 식별정보를 제외한 AI 이미지 편집본이다. 두 편집본의 발언 문구는 원본과 대조했다.
