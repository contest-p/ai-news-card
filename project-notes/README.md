# 프로젝트 작업 기록

이 폴더는 제출 문서가 아닌 작업·검증 이력을 보관한다. 최종 제출본은 저장소 루트의 [README 제출 항목표](../README.md#제출-항목)와 `docs/`의 네 문서를 확인한다.

- `05~08_개인_PRD`: 담당별 초기 작업 범위. 당시 기술 선택과 완료 기준이 포함되어 있으며, 최신 구현 상태를 뜻하지 않는다.
- `09~15_*.md`: 구현 검토, 연결·발송 설정, 배포 검증과 평가 근거의 날짜별 기록. 과거 점검 결과와 현재 상태를 구분해 읽는다.
- `presentation/`: 최종본 이전 발표 PDF·PowerPoint와 화면 캡처, 제작 기록. 최종 발표본은 [`docs/presentation/`의 PDF](../docs/presentation/ai-news-briefing-presentation-latest.pdf)다.
- `user-test/assets/`: [사용자 피드백 기록](../docs/05_사용자_피드백_기록.md)에 연결된 익명 문제 화면 이미지.

이 폴더의 파일은 이력과 재검토 근거를 위해 유지하며, 평가자에게 제출할 문서로는 `docs/`의 최종본을 사용한다.
